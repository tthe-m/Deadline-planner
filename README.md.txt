# Планувальник дедлайну
Обчислює дату, що настане через задану кількість робочих днів від указаної, пропускаючи суботи й неділі. Приклад: «07.08.2026 + 10» → «21.08.2026»
## Як зібрати
- відкрити файл Deadline planner.sln у Visual Studio 2026;
- обрати конфігурацію Debug і платформу x64;
- виконати Збірка -> Зібрати рішення (Ctrl+Shift+B).
## Як запустити
Запустити без налагодження (Ctrl+F5) або відкрити зібраний файл
Deadline planner.exe з папки x64\Debug.
## Приклад роботи
```
Input date (dd.mm.yyyy): 09.09.2026
Input workday amount: 30
Result: 14.10.2026
Repeat the program?(y/n): n
```
## Що програма не приймає
- порожній рядок;
- некоректний формат дати;
- неправильні дати;
- від’ємну кількість робочих днів.
